ONE PROJECT • MULTIPLE LOCATIONS

THE BEST QUOTE STARTS WITH THE ENTIRE PROPERTY.

Multiple-stump work is easier to plan when every stump is included from the beginning. Size, quantity, access and distance between work areas all affect how the project is organized.

Rather than sending isolated close-ups, provide a numbered photo of each stump and a wider view showing where it sits on the property.

  • Number each stump in the photo set
  • Include a diameter measurement for each
  • Show access to every work area
  • Identify which stumps require deeper grinding

HOW MULTIPLE STUMPS ARE PRICED.

The total quote reflects stump sizes, root flare, number of locations, equipment access, travel between work areas, grinding depth and chip handling.

Several smaller stumps may be more efficient to complete together than as separate appointments, but the actual savings depend on site conditions.

FAQ

MULTIPLE STUMP REMOVAL QUESTIONS

Is there a lower per-stump cost for several stumps?

Sometimes. Grouping work can improve efficiency, but size, access and distance between stumps still affect the total project.

How should I photograph multiple stumps?

Number each stump, include a measurement photo and provide a wider property view showing its location and access route.

Can some stumps be ground deeper than others?

Yes. Explain the future use of each area so depth can be discussed individually.

Can you work with landscapers or fence contractors?

Yes. The stump scope can be coordinated around the planned installation or property improvement.
